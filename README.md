🕹️ JosJis Clicker

JosJis Clicker is a simple and fun clicker game where players can:

- 🪙 Earn coins by clicking the character.
- ⚡ Upgrade Power Click to earn more coins per click.
- 🤖 Purchase Auto Clicker upgrades to earn coins automatically.
- 🎁 Collect Daily Rewards.
- 🔄 Reset game progress and start again.

💾 Game Progress

Game progress is saved locally in your browser using LocalStorage.

Please note:

- Progress is saved on the current browser and device.
- Clearing browser data may erase saved progress.
- Game coins are virtual points and are not real cryptocurrency.
- Game coins cannot currently be exchanged for JJS tokens or other assets.
